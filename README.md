# ICS344 Course Project – Attack & Defense

This project demonstrates an end-to-end security scenario using Kali Linux (attacker) and Metasploitable3 (victim).

## Phases:
- **Phase 1**: Brute-force SSH using Hydra + Nmap scan
- **Phase 2**: Log analysis with Splunk SIEM
- **Phase 3**: Defense using Fail2Ban and result validation
